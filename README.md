# 🏦 Bank Customer Churn Prediction

This project predicts whether a **bank customer is likely to leave (churn)** or stay with the bank using **Machine Learning**.  
It uses a **Random Forest Classifier** and a **Streamlit web application** for interactive predictions.

---

## 🚀 Project Highlights
- End-to-end Machine Learning project
- Random Forest based churn prediction
- Feature scaling using StandardScaler
- Interactive Streamlit web application
- Real-world banking use case

---

## 🧠 Machine Learning Overview
- Supervised classification problem
- Model: Random Forest Classifier
- Data preprocessing and feature scaling
- Model persistence using Pickle
- Prediction based on customer attributes

---

## 📊 Input Features
The model uses the following customer information:
- Credit Score  
- Country  
- Gender  
- Age  
- Tenure  
- Account Balance  
- Number of Products  
- Credit Card Availability  
- Active Member Status  
- Estimated Salary

## ▶️ How to Run the Project

### Step 1: Clone the Repository
git clone https://github.com/your-username/Bank-Customer-Churn-Prediction.git
cd Bank-Customer-Churn-Prediction



Step 2: Install Dependencies

pip install -r requirements.txt

Step 3: Run the Streamlit App
streamlit run app.py

📈 Output

Predicts whether a customer will Stay or Leave

Provides basic business recommendations based on prediction
